The Consensus REST API gives you programmatic search over more than 200 million peer-reviewed papers. Send a research query and get back ranked results as JSON: titles, authors, journals, citation counts, DOIs, and AI summaries, all in a single call. Sources include Semantic Scholar, OpenAlex, and PubMed, and ranking is hybrid (vector plus lexical), weighted by relevance, study quality, and recency.

## Base URL

Every request goes to a single base URL over HTTPS:

```
https://api.consensus.app
```

## Authentication

The API authenticates every request with an API key passed in the `x-api-key` header. It is not a Bearer token.

```bash
curl -G https://api.consensus.app/v1/search \
  -H "x-api-key: $CONSENSUS_API_KEY" \
  --data-urlencode "query=does creatine improve muscle strength"
```

Get a key from the [API dashboard](https://consensus.app/subscription/api/). See [Authentication](/authentication) for how keys work, and [Rate limits and tiers](/rate-limits-and-tiers) for what each plan returns.

## Responses

A successful search returns `200` with a JSON object: a `results` array plus pagination fields (`page`, `page_size`, `is_end`, `next_page`). See [Filtering results](/api-reference/filters) for every query parameter and [Pagination](/api-reference/pagination) for how to page through a result set.

## HTTP status codes

| Status | Meaning |
| ------ | ------- |
| `200` | Success. The response body contains your results. |
| `400` | Bad request. The request was malformed. |
| `401` | Unauthorized. Your `x-api-key` header is missing or invalid. |
| `403` | Forbidden. The key is valid but not permitted to access the requested resource or field. |
| `404` | Not found. The route or resource does not exist. |
| `422` | Unprocessable entity. A query parameter failed validation. |
| `429` | Too many requests. You are rate limited. Check the `Retry-After` header and back off. |
| `500` | Internal server error. Something went wrong on our side. Retry after a short delay. |

See [Errors](/api-reference/errors) for response shapes and handling guidance.
