This guide takes you from zero to a working search: get a key, authenticate, and read the results.

<Steps>
  <Step title="Get an API key">
    Sign in at the [API dashboard](https://consensus.app/subscription/api/) and create a key. Treat it like a password: it carries your plan's access and quota. See [Authentication](/authentication) for how keys work.
  </Step>
  <Step title="Export your key">
    Store the key in an environment variable so it stays out of your code and version control.

    ```bash
    export CONSENSUS_API_KEY="your_api_key"
    ```
  </Step>
  <Step title="Make your first request">
    Send a `query` to `GET /v1/search` with your key in the `x-api-key` header. With curl, use `--data-urlencode` so the query is encoded correctly.

    <CodeGroup>

    ```bash curl
    curl -G https://api.consensus.app/v1/search \
      -H "x-api-key: $CONSENSUS_API_KEY" \
      --data-urlencode "query=does creatine improve muscle strength" \
      --data-urlencode "page_size=5"
    ```

    ```python Python
    import os
    import requests

    resp = requests.get(
        "https://api.consensus.app/v1/search",
        headers={"x-api-key": os.environ["CONSENSUS_API_KEY"]},
        params={
            "query": "does creatine improve muscle strength",
            "page_size": 5,
        },
    )
    resp.raise_for_status()
    data = resp.json()
    for paper in data["results"]:
        print(paper["title"], paper.get("takeaway"))
    ```

    ```javascript JavaScript
    const params = new URLSearchParams({
      query: "does creatine improve muscle strength",
      page_size: "5",
    });

    const res = await fetch(`https://api.consensus.app/v1/search?${params}`, {
      headers: { "x-api-key": process.env.CONSENSUS_API_KEY },
    });
    if (!res.ok) throw new Error(`Request failed with status ${res.status}`);
    const data = await res.json();
    for (const paper of data.results) {
      console.log(paper.title, paper.takeaway);
    }
    ```

    </CodeGroup>
  </Step>
  <Step title="Read the response">
    The response is a JSON object with a `results` array and pagination fields. Here is one result, trimmed for clarity:

    ```json
    {
      "results": [
        {
          "title": "Effects of creatine supplementation on muscular strength and body composition: a meta-analysis",
          "authors": ["J. Smith", "A. Patel"],
          "journal_name": "Journal of Strength and Conditioning Research",
          "publish_year": 2018,
          "doi": "10.1519/JSC.0000000000002220",
          "citation_count": 214,
          "study_type": "meta-analysis",
          "takeaway": "Creatine combined with resistance training increases muscular strength more than training alone.",
          "url": "https://consensus.app/papers/..."
        }
      ],
      "page": 0,
      "page_size": 5,
      "is_end": false,
      "next_page": 1
    }
    ```

    The key fields on each result:

    <ResponseField name="title" type="string">
      Title of the paper.
    </ResponseField>
    <ResponseField name="authors" type="string[]">
      List of the paper's authors.
    </ResponseField>
    <ResponseField name="journal_name" type="string">
      Journal the paper was published in.
    </ResponseField>
    <ResponseField name="publish_year" type="integer">
      Year of publication.
    </ResponseField>
    <ResponseField name="doi" type="string">
      Digital Object Identifier for the paper. DOI access is included with [Enterprise](/enterprise/full-text-and-fields) plans.
    </ResponseField>
    <ResponseField name="citation_count" type="integer">
      Number of times the paper has been cited.
    </ResponseField>
    <ResponseField name="study_type" type="string | null">
      Classified study design, such as `rct` or `meta-analysis`. Requires Pro or higher.
    </ResponseField>
    <ResponseField name="takeaway" type="string | null">
      One-sentence AI summary of the paper's key finding. Requires Pro or higher.
    </ResponseField>
    <ResponseField name="url" type="string">
      Consensus URL with the full paper details.
    </ResponseField>

    <Note>
      `study_type` and `takeaway` are returned on Pro, Deep, Teams, and Enterprise plans. On Free and anonymous access they are `null`. See [Rate limits and tiers](/rate-limits-and-tiers) for the fields each plan returns.
    </Note>
  </Step>
</Steps>

For the complete result schema and every response field, see the [Search papers](/api-reference/endpoints/search) reference. To read past the first page of results, see [Pagination](/api-reference/pagination).
