Consensus is an AI search engine for research. It searches **over 200 million peer-reviewed papers** and returns ranked results with grounded, DOI-linked citations and AI summaries. This is the developer platform: everything you need to bring that same research layer into your own apps, agents, and workflows.

## Start in under a minute

Get a key from the [API dashboard](https://consensus.app/subscription/api/), then run your first search:

<CodeGroup>

```bash curl
curl -G https://api.consensus.app/v1/search \
  -H "x-api-key: $CONSENSUS_API_KEY" \
  --data-urlencode "query=does creatine improve muscle strength" \
  --data-urlencode "study_types=rct,meta-analysis" \
  --data-urlencode "page_size=5"
```

```python Python
import os, requests

resp = requests.get(
    "https://api.consensus.app/v1/search",
    headers={"x-api-key": os.environ["CONSENSUS_API_KEY"]},
    params={
        "query": "does creatine improve muscle strength",
        "study_types": "rct,meta-analysis",
        "page_size": 5,
    },
)
resp.raise_for_status()
for paper in resp.json()["results"]:
    print(f"{paper['title']}: {paper.get('takeaway')}")
```

```javascript JavaScript
const params = new URLSearchParams({
  query: "does creatine improve muscle strength",
  study_types: "rct,meta-analysis",
  page_size: "5",
});

const res = await fetch(`https://api.consensus.app/v1/search?${params}`, {
  headers: { "x-api-key": process.env.CONSENSUS_API_KEY },
});
const { results } = await res.json();
console.log(results.map((p) => p.title));
```
