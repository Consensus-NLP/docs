---
title: "Connect a client"
description: "Step-by-step setup to connect Consensus to Claude Desktop, Claude Code, ChatGPT, Cursor, Codex, VS Code, Windsurf, and other MCP clients."
---

Connect Consensus to your client by pointing it at the server URL:

```
https://mcp.consensus.app/mcp
```

<Warning>
  Always include the `/mcp` suffix. The transport is streamable HTTP.
</Warning>

<Note>
  Most clients handle OAuth automatically: the first search opens a browser window to sign in and approve access, with no keys to copy. See [Authentication](/mcp/authentication) for details and the Enterprise Bearer option.
</Note>

<Tabs>
  <Tab title="Claude Desktop">
    Connect from the app settings, no config file needed.

    <Steps>
      <Step title="Open connectors">
        Go to **Settings** then **Connectors**.
      </Step>
      <Step title="Connect Consensus">
        Find **Consensus** in the list and select **Connect**. OAuth runs automatically.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Claude Code">
    Add the server from your terminal:

    ```bash
    claude mcp add --transport http consensus https://mcp.consensus.app/mcp
    ```

    OAuth opens in your browser the first time Consensus is called. Manage the connection any time with the `/mcp` command.
  </Tab>

  <Tab title="ChatGPT">
    <Steps>
      <Step title="Open Apps">
        In the ChatGPT sidebar, open **Apps**.
      </Step>
      <Step title="Connect Consensus">
        Search for **Consensus** and select **Connect**.
      </Step>
    </Steps>

    Results render in an interactive widget. Deep Research can call Consensus too: prompt it with "Use Consensus to research...".
  </Tab>

  <Tab title="Cursor">
    Open **Settings** then **Tools & MCP** then **New MCP Server**, or add this to your MCP config:

    ```json
    {
      "mcpServers": {
        "Consensus": {
          "command": "npx",
          "args": ["-y", "mcp-remote@latest", "https://mcp.consensus.app/mcp"]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Codex">
    Add the server, then log in:

    ```bash
    codex mcp add consensus --url https://mcp.consensus.app/mcp
    codex mcp login consensus
    ```

    <Note>
      Codex uses `--url`, not `--transport http`.
    </Note>
  </Tab>

  <Tab title="VS Code (GitHub Copilot)">
    Add Consensus to your MCP configuration:

    ```json
    {
      "servers": {
        "Consensus": {
          "url": "https://mcp.consensus.app/mcp"
        }
      },
      "inputs": []
    }
    ```
  </Tab>

  <Tab title="Windsurf">
    Open **Settings** then **Cascade** then **MCP Servers**, or add this to your config:

    ```json
    {
      "mcpServers": {
        "consensus": {
          "serverUrl": "https://mcp.consensus.app/mcp"
        }
      }
    }
    ```
  </Tab>

  <Tab title="Other clients">
    Any client that supports streamable HTTP MCP can connect. Point it at:

    ```
    https://mcp.consensus.app/mcp
    ```

    OAuth runs automatically if the client supports it. For clients that accept a static token instead, use the Enterprise Bearer option in [Authentication](/mcp/authentication).
  </Tab>
</Tabs>
