Enterprise uses the same authentication as the rest of the platform, scoped to your organization. This page covers how you authenticate, how access is scoped, and where to get security and compliance documentation.

## Authentication

You reach Consensus two ways, and each has its own auth.

### REST API keys

The [REST API](/api-reference/overview) authenticates with an API key sent in the `x-api-key` header. It is an API key, not a Bearer token.

```bash
curl -G https://api.consensus.app/v1/search \
  -H "x-api-key: $CONSENSUS_API_KEY" \
  --data-urlencode "query=immunotherapy for melanoma"
```

Enterprise API keys are scoped to your organization. Manage them from your [API dashboard](https://consensus.app/subscription/api/). For the full authentication reference, see [Authentication](/authentication).

<Warning>
  Treat API keys as secrets. Keep them server-side, load them from environment variables or a secrets manager, and never commit them or ship them in client-side code. Rotate keys on a regular schedule and immediately if you suspect one is exposed: generate a replacement from your API dashboard and retire the old key.
</Warning>

### MCP authentication

The [MCP server](/mcp/authentication) uses OAuth 2.1 (Authorization Code with PKCE and dynamic client registration) so interactive clients like Claude, ChatGPT, and Cursor can connect and sign in through the browser.

For programmatic and agent access, Enterprise can authenticate to the MCP server with a Bearer token:

```
Authorization: Bearer YOUR_API_KEY
```

See [MCP authentication](/mcp/authentication) for the connection and OAuth details.

## Organization-scoped access

Enterprise API keys are scoped to your organization, so usage, limits, and access apply at the organization level rather than to a single personal account.

Single sign-on (SSO) is available for Enterprise organizations. The identity providers and exact configuration are set up with your team during onboarding. For SSO specifics, contact [sales](https://consensus.app/home/contact/).

## Data handling

All API and MCP traffic is served over HTTPS. Your API keys keep access scoped to your organization, and Consensus searches published, peer-reviewed literature.

For data processing terms, security reviews, and current compliance and security documentation, contact [sales](https://consensus.app/home/api/). We can share the latest documentation for your review.
