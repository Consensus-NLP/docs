Someone states a claim as fact. You want to know what the peer-reviewed literature actually says, with citations.

## How Consensus helps

Phrase the claim as a question and Consensus returns ranked papers, each with a one-sentence `takeaway` that states its finding. You collect that evidence, weigh support against refutation, and cite the sources. In the web app, the Consensus Meter does the aggregation for you: it summarizes yes, no, and possibly signals across papers into a single snapshot.

## Recipe

<Steps>
  <Step title="Extract the claim">
    Reduce the statement to one checkable proposition and phrase it as a question, for example "does vitamin C prevent the common cold".
  </Step>
  <Step title="Search for evidence">
    Query the claim and restrict to high-evidence designs (`meta-analysis`, `systematic review`, `rct`) so the answer rests on strong studies.
  </Step>
  <Step title="Read each stance">
    Use each paper's `takeaway` to see whether it supports, refutes, or qualifies the claim.
  </Step>
  <Step title="Return a verdict">
    Tally the stances into a verdict and present it with the citations that back it.
  </Step>
</Steps>

```python
import os, requests

CLAIM = "vitamin C prevents the common cold"

resp = requests.get(
    "https://api.consensus.app/v1/search",
    headers={"x-api-key": os.environ["CONSENSUS_API_KEY"]},
    params={
        "query": f"does {CLAIM}",
        "study_types": "meta-analysis,systematic review,rct",
        "page_size": 10,
    },
)
resp.raise_for_status()
papers = resp.json()["results"]

print(f"Claim: {CLAIM}")
print(f"Reviewed {len(papers)} peer-reviewed papers.\n")
for i, paper in enumerate(papers, start=1):
    evidence = paper.get("takeaway") or paper["abstract"][:200]
    link = f"https://doi.org/{paper['doi']}" if paper.get("doi") else paper["url"]
    design = paper.get("study_type", "study")
    print(f"[{i}] ({design}) {evidence}")
    print(f"    {link}\n")
```

The result is a citation-backed evidence brief. To collapse it into a verdict, classify each takeaway by stance and tally the results.

## Filters that help

- `study_types`: prefer `meta-analysis` and `systematic review`, which already aggregate primary studies.
- `sjr_max`: cap the journal quartile (`1` is Q1) to weight stronger venues.
- `exclude_preprints`: restrict to peer-reviewed evidence for a claim that matters.
- `year_min`: prefer current evidence when a field moves quickly.

See the full set in [Filters](/api-reference/filters).

<Warning>
  The Consensus Meter is a heuristic snapshot, not a formal meta-analysis. It weighs the retrieved papers, which are a sample of the literature, and AI takeaways are LLM-generated. Treat any automated verdict as a starting point and read the cited papers before you publish, advise, or decide.
</Warning>

<Note>
  This is not medical, legal, or financial advice. Consensus surfaces and summarizes research; it does not replace a professional.
</Note>
