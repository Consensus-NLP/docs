[Consensus](https://consensus.app) is an AI search engine for research. It searches **over 200 million peer-reviewed papers** (drawing on sources like Semantic Scholar, OpenAlex, and PubMed) and returns ranked results with grounded, DOI-linked citations and AI summaries. Ranking is hybrid: it combines vector and lexical matching, then weights results by relevance, study quality, and recency.

This section documents the web product at [consensus.app](https://consensus.app), the same product researchers, students, and clinicians use every day. If you are a developer evaluating Consensus, the web app is the fastest way to see how the data, ranking, and analysis behave before you reach for the [API](/api-reference/overview) or the [MCP server](/mcp/overview).

## Who it is for

- **Researchers, students, and clinicians** who need evidence-backed answers and citations they can trust.
- **Developers** deciding whether Consensus fits their product, and who want to see the underlying data and ranking in practice.

## Core surfaces

The web app is built around five things you can do with the literature.

- **Search.** Ask a research question in plain language. Run a fast [Quick Search](/web/searching) for ranked results, or Pro and Deep research for a multi-step agent that synthesizes a cited answer.
- **The Consensus Meter.** For yes/no questions, it aggregates supporting, opposing, and mixed evidence across papers into a quick snapshot of where the literature leans.
- **Paper analysis.** Every result carries a one-sentence AI takeaway, structured study details, and a deeper study analysis (design, sample, citations, and more). See [understanding results](/web/understanding-results).
- **Citation export.** Export any paper as BibTeX, RIS, or EndNote, or copy an inline citation in APA, MLA, Chicago, or Vancouver style.
- **Collections.** Save papers to collections to build a working library for a project, question, or manuscript.

## Web, API, or MCP

Consensus exposes the same research layer through three surfaces. Pick the one that matches how you want to work.

| Surface | What it is | Reach for it when |
| --- | --- | --- |
| **Web** | The interactive product at consensus.app | You want to read, explore, and export citations yourself |
| **REST API** | A JSON endpoint over the paper index, authenticated with `x-api-key` | You are embedding search into your own app or data pipeline |
| **MCP server** | A hosted tool server using OAuth 2.1 | You want an LLM agent (Claude, ChatGPT, Cursor) to search papers as a tool |
