Every paper in Consensus is a real, citable source with a DOI. When you find work worth keeping, save it to a collection and cite it without retyping anything.

## Export a citation

Consensus gives you two ways to cite a paper: download a file for your reference manager, or copy a formatted citation straight into your document.

### File formats for reference managers

Export a paper as a file, then import it into the tool where you manage your library.

| Format | Reach for it when |
| --- | --- |
| **BibTeX** | You write in LaTeX or Overleaf |
| **RIS** | You import into Zotero, Mendeley, or another reference manager |
| **EndNote** | You keep your library in EndNote |

<Tip>
  RIS is the most widely supported interchange format. If your reference manager is not listed, it almost certainly imports RIS.
</Tip>

### Inline citation styles

Copy a ready-formatted citation and paste it directly into a document. Pick the style your journal, publisher, or instructor requires.

| Style | Common in |
| --- | --- |
| **APA** | Psychology and the social sciences |
| **MLA** | The humanities |
| **Chicago** | History, and some business and publishing |
| **Vancouver** | Medicine and the biomedical sciences |

## Collections and your library

Save any paper to a collection to build a working library. Group papers by project, research question, or manuscript, and return to them whenever you continue the work. Collections are where a search session turns into a durable set of sources you can cite and revisit.

## Build a literature review

Collections and citation export work together for a literature review: gather the relevant papers into one collection as you search, screen their abstracts and [study details](/web/understanding-results), then export citations in the format your reference manager reads.

## Build citations in your own app

If you are generating citations programmatically, the [API](/api-reference/overview) returns the bibliographic fields you need to format any style yourself: `doi`, `authors`, `journal_name`, `publish_year`, `volume`, `pages`, and `url`.

<Note>
  Building a research tool or pipeline? The [REST API](/api-reference/overview) and [MCP server](/mcp/overview) expose the same paper index and metadata behind the web app.
</Note>
