title: "Build with the API and MCP"
description: "Access the Consensus research layer programmatically through the REST API or the MCP server."
---

Prefer to build on Consensus rather than click through the app? The same research layer, over 200 million peer-reviewed papers with grounded, DOI-linked citations, is available programmatically. Use the REST API to call Consensus from your own code, or the MCP server to give an AI assistant or agent live access to Consensus search.

  <Card title="MCP server" icon="plug" href="https://docs.consensus.app/docs/mcp">
